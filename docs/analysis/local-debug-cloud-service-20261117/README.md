# 本机开发与云端正式服务切换

2026-11-17，基线 main `31bc74f`（#79）。用户要求物理机承担 Codex 和调试，
当前云主机专用于游戏服务，原云主机退出。地址与凭据均私有保存。
公开摘要见 [acceptance.json](acceptance.json)，日常入口见 [工作分工](../../remote-development.md)。

## 迁移结果

- 源游戏服务停止写入并取消自动启动后，导出数据库和恢复归档。
- 在新的正式库恢复 5 张表；accounts 15、players 5、sessions 1、shared_records 0、users 5。
  每张表的行数及完整内容摘要与源快照一致，账号密码哈希、稳定玩家 ID 和存档原样保留。
- 23,099 个资源文件逐文件摘要一致，逻辑总长 1,354,668,340 字节。
- 数据库 dump 和恢复包在本机、现云端各存一份，传输前后摘要一致；私有恢复包包含旧代码、
  配置、日志、运行目录和额外表备份。常用游戏资源另有已验证副本，不要求旧主机继续在线。
- 正式代码运行于 `/srv/onisoul/server`，资源沿用 `/srv/onisoul/assets/pc`；
  `onisoul-stub`、`onisoul-proxy` 已启动并开机自启，MySQL 仅监听回环。
- 旧开发 service 已停止且取消自动启动；云端 Codex 进程已停止，原 tmux 会话已结束。

上表为停止写入时的快照。之后正常登录会更新 session 等记录，不应据此要求运行库始终维持原摘要。
旧游戏服务已停止、无需继续提供服务；云主机订阅/实例释放由用户自行处理。

## 本机调试及连接

已在物理机准备独立 Python 环境、分析/媒体依赖和 MySQL 免安装运行文件。
本机完整回归共 **659 项，659 通过、无跳过、无失败**，包括真实 SQL 和 Windows DPAPI。
临时实例收到正常 shutdown 后退出、临时目录清除，未安装 Windows MySQL 服务。
后续使用 `powershell -File tools/test_local.ps1`，路径读取本机私有 development.local.json。

本机旧 80 端口是历史自定义转发脚本；核对命令、端口、PID 和启动时间后，
用户通过管理员脚本停止。新入口安装到客户端目录，连接信息读取私有 connection.local.json。
实际验证了 relay 替换、同一进程复用、登录保存助手和游戏域名健康检查。
转发进程由普通用户运行，日志和进程身份记录留在本机私有目录。

原 Qt 登录页回填已保存的账号，提交后成功进入 Unity 标题页；点击进入后显示“鬼友介绍”页面。
本账号处于建号前流程，本次未替用户选择国家或创建角色，未将该结果记作主城/玩法验收。
云端临时账号 HTTP 验证覆盖注册、登录、命名、建号、重登、编队、任务奖励、道路及建设的既有范围，
测试账号已清理。云服务健康和本机游戏域名均返回正常。

## 仓库调整与隐私

AGENTS、首页、导航、开发和部署说明统一为本机开发/云端服务；systemd 模板使用新运行布局。
新增客户端安装入口、本机私有配置模板、Windows/Linux 隔离 SQL 回归及本机快捷测试入口。
国家包离线构建不再暗含旧服务器地址；联网来源必须明确传入，已有离线来源不变。

当前受跟踪文件中的真实公网 IP 已替换为占位符，私钥、数据库 dump、恢复包、
真实连接配置不入库。新增 check_public_config 工具核对实际暂存内容，检查结果不打印匹配值；
测试覆盖“暂存中仍有地址而工作副本已改掉”、私有文件名、凭据标记及合法本地示例。
历史环境报告标明已被本次分工替代。普通 PR 不重写 Git 历史，旧提交仍可见原记录。

证据分别保留在本机 work/service-cutover-20261117 和云端私有迁移备份目录，
公开附件只保留不含主机地址、个人路径、账号标识或凭据的汇总。
本次调整没有补完任何新增玩法，也没有把已知缺图或未接入接口计为完成。
