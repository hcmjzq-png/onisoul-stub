## 语音检查与边界

每类原表引用 105 个音频名，其中 1 个静音占位由所有类别共用，故合计 `8×104+1=833`。正式路径由实际客户端规则 `MD5(音频名的 UTF-16LE 字节)` 得到，位于 `/client/pc/jp/assets/vse/`。

沿本机客户端使用的链路检查：hosts → 本机 relay:80 → 当前云端 proxy80 → stub。检查中出现过暂时性 502 和未完整读取响应；最终以完整响应长度、SHA256 和对象名核对，不将一次 200 或空读视为成功。未定位瞬时网关现象的根因，不能据此断言客户端无声是资源缺失。

[voices.tsv](voices.tsv) 是 833 个正式 URL 的最终内容摘要与来源；现有语音无须再次发布。本次 8 段播放使用独立 QA 客户端及既有 PC 转换包，覆盖各类首个问候音的解码和播放结束；未验收正式游戏内所有语音触发、音量设置或跨场景中断。
