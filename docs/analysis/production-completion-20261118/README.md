# 本机生产与商店

配方菜单、单体开工和批量开工共用配方资格。任务 4 完成且任务 5 已接取时，
G1 田地可用一次 10 秒免费配方。成功收获时同事务记录教学完成，取消允许重做。
田地、伐木所和炼铁所开放各自 15 分钟基础配方，玩家等级门槛继续用于其他常规配方。

主城生产涵盖手动、单次及自动，收获更新物品、经验和耐久，自动建筑有耐久时续产。
批量、取消、表内加速费、建筑进化和好友生产都通过现有路由和存档事务。
本机游戏表通过 `ONI_TABLE_DIR` 读取。新增读取项见 [表依赖](../server_tables.tsv)。

原表提供时间、费用、产量区间、经验、耐久、奖励候选和材料。
未能从客户端确认的奖励抽选、道路和智力叠加、协作、好友奖励分配及进化状态重置采用本服兼容规则。
收获失败可重试，同一轮已发放的奖励只能领取一次。
用原表及隔离时钟运行后端探针，1,186 组建筑配方、5 个好友建筑品级和 488 条进化关系通过。
探针另核验关闭的 14 组其他短配方。客户端操作待统一实测。

本机抓包中，`politic/shop/buyShopItem` 接收商品 `shop0000041`、`index=-1` 后，
返回 `integer parameter out of range`，未继续收到建设请求。客户端将 `-1` 用作整套订单，
见 `ShopItemBuild.cs:146` 和 `ShopItemSupport.cs:329`。整套购买接受该值，
逐件订单仍校验商品下标。隔离 SQL/HTTP 回归覆盖扣款、图纸入库、重登及图纸进入建设任务。

本机抓包和按本机存档国家复算均得到 7 项图纸和 23 项消耗品。原表 88 项图纸中有 80 项未标记初始销售，
另有一项初始图纸的国家映射无法交付。32 项初始消耗品里，9 项未配置价格。
国家商店仍是空回包，限时商品的开放条件有待核对。

## 普通商店上架规则

任务 8 的 `acceptUnlocks` 含 `unlockShop`。接受前普通商品锁定，接受后初始商品开放购买。
`building` 的三组 `openLevelN` 与 `openShopItemIdN` 指向 60 种非初始图纸，剩余 20 种暂无明确门槛。
完工、升级或进化到指定建筑等级会记录解锁；同一商品有多个来源时，达到任意一个即可。
`shopUnlockedItems` 只存于玩家存档。收纳、出售后保留已解锁商品，旧存档从现存的已完工建筑补记。
历史已经移除的建筑没有可验证的存档记录，无法据此补记。

商店列表和购买共用资格。交付和价格有效但未解锁的商品返回客户端已识别的 `state=lock`，
直购请求也会被拒绝。可交付的主城图纸须有有效的物品、图纸与主城建筑定义。
原表隔离验证覆盖任务 8 开店、田地到植林地和精炼炉的开锁链、田地 Lv7 解锁水田、
未知门槛拒绝扣款，以及旧存档回填后出售建筑仍能回购。
