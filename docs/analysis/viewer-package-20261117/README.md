## 查看器程序及其他资料的作用

已静态反编译主 EXE 全部 51 个方法；主程序集为 .NET 2.0 x86 WinForms，引用 System.Drawing、IrisSkin2 等。7 个类型包含窗体、索引对象及程序集辅助类型。未运行来源程序，运行兼容性不作实测结论。
- `Font1.cs:397–401`：从原 PNG 读取，再按 (-90,-140,400,400) 缩放显示；`Form2.cs:22–26` 大图使用 (0,-150,600,600)。这些是查看器布局参数，不是游戏裁切契约。应直接使用原 PNG，避免截取查看器的缩放画面。
- `Font1.cs:406–424`：加载并排序 SoulPic；`506–538`：按顺序装入 G1/G3/G5/G7；`554–556`：流水号到文件名。可借鉴为离线角色检索、进阶形象对照、资源验收缩略图和人工校对工具。
- 搜索支持姓名/声优/画师正则，未加无效正则保护；图像和 Graphics 缺少对应 Dispose，反复查看存在文件锁与资源累积风险（静态推断，未动态压测）。调试按钮只向 debug.txt 写校对号，未发现图片导出或游戏解包器实现。
- `IrisSkin2.dll` 为查看器换肤依赖（158 个类型、8,193 个方法、5 个嵌入 UI BMP）；MP10.ssk 为皮肤文件。它们不提供 Unity AssetBundle、音频、网格或原游戏业务逻辑。
- 城市 JPG 可用于主城布局与截图验收；传递流、内政加成及攻略笔记可建立待核实问题清单。玩家经验数字、掉落和产出结论未对原表/原客户端验证，未写进 stub 规则。
- 包中没有语音文件、动画、Mesh、Shader、Unity 场景、原游戏 Assembly-CSharp、服务器响应模板或完整数值表。它不能补齐这些类别，也不代表抽卡、养成、生产或交易业务已经实现。
