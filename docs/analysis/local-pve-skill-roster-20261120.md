# 本地 PvE 技能测试队

目标是在现有本地普通恶鬼入口用鬼物语编队检验武将技能。通过条件为五将与技能槽重登一致、真实战报有玩家 `execSkill` 及属性变化、重复开战只扣一次恶鬼点数。测试代码以远端 `main` 的 `de2f5cc` 为基线。本机运行目录源码为 `b22be07` 及已有工作树改动，实例健康检查标签为 `local-story-tutorial-battle-c4092c6`。

原表 `skill.json`、`skillMessage.json` 提供技能 ID、效果、适用玩法和发动率。测试卡的技能按 G2、G4、G6 开眼，等级取原表 `changeLevel`，发动仍由既有结算器判定。五将用原表基础攻防智，品阶按测试所需开眼数配置。编队脚本只向新建的本地测试角色发卡，随后调用 `deck/setDecks` 写入 `quest.0`。国技「專用技解禁【攻】」的等级条件和装备技「無刀之極意」留待对应业务验证。测试队用三阵营条件的「紫陽花【壹】」提供暴击率。

卡名、阵营取 `character.json`、`item01.json` 与 `item01Message.json`。图册立绘按截图形象比对，山科那奈与千於銀按用户指示选普通版；图册编号与原始 PC 包的品阶映射未经确认。大立绘保留源图像素，小图使用同一立绘缩放，技能牌使用新绘的「本地测试」标签。发布清单留在本机，五个武将包和九个技能包的名称、纹理尺寸和 RGBA 像素经 UnityPy 读回校验。`assets` 和 `assets2` 两条路径对 14 个包均返回 HTTP 200，响应摘要与当前发布文件一致。初次临时卡牌替换前核对了本轮旧摘要。

- 已有运行目录的 `tests.test_raid_battles`、`tests.test_local_card_skills` 共 14 项通过。
- 本地入口经网页注册、建号、编成、重登后读到五张武将和九项技能。第一场战报记 8 项玩家技能发动，队伍攻击 4,301→27,410，造成伤害 45,057，普通恶鬼生命 50,000→4,943，点数 100→80。两个并发请求及重登重试的战报主体与 SQL 回执一致，仅扣一次点数。
- 交给用户的独立测试档通过同一编队与重登检查，保留 100 点恶鬼点数和满血 50,000 的普通恶鬼。登录资料保存在本机私有配置目录。原 PC 此时正开着另一存档，当前记录的客户端范围为窗口和本地环境确认。下一步用准备好的角色进入恶鬼罗刹，核对出战立绘、技能牌和结算画面。

按本机发布清单核对摘要即可撤回本轮新增的包。切回原测试角色可恢复原测试流程。未改路由或生产环境。
