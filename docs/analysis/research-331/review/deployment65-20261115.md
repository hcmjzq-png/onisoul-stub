## 真机发现的经验保存错误及本 PR 修复

任务 1 的真实表奖励是 `item11_0000501 × 25`。原 `RewardProcessor.cs:29,260–264`
调用 addExpValue；这是角色经验。线上 #65 却将其放入 items，导致 entity.exp 仍为 0。
临时测试档确实出现 `items.item11_0000501=25, entity.exp=0`。
旧测试样本还把前 3 个任务的该条奖励误写成 `item11_0000801`，掩盖了错误。

本 PR 改为向 entity.exp 累加，不作为库存或付费货币；纠正上述三条样本，与原表逐一核对 ID/数量。
不自动升等级，仍沿用原有升级接口与条件；不改变随机奖励、容量溢出等尚未还原的规则。
增加/扩展重登读取、重复领奖不重复增加、错误批次不保存经验或领奖记录的测试。

本次代码回归共 617 项：隔离 MySQL 环境 614 通过、3 项可选 IL 依赖跳过；这 3 项已在分析环境补跑通过。
