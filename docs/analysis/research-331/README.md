## 外部资料能解决什么

原客户端通常能确认请求、字段类型、UI 条件、表 ID 和部分计算；
外部官方/玩家材料有助确认开放条件、操作时序、费用、倍率、叠加、周期及版本变化。
它们不能直接恢复原始网络回包、丢失的资源字节、从未记录过的历史战况，
也不能替代服务端事务、状态生产和通知实现。

参见 [共同工作规则](COMMON.md)、[已预查资料入口](SOURCES.md)。
每组必须区分可靠规则、待验证假设、本服兼容策略和仍不支持的行为；
不能把别组缺生产端或基础设施的问题笼统标为“必须找到外部资料”。
