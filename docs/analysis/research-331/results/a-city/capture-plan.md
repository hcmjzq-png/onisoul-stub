# 总集成独占客户端取证

不启动第二个 Unity，不改原始尺寸；调试监控面板与游戏等大对齐。
本机与局域网分别记录客户端→hosts→proxy80→stub，不在 A 工作树部署或操作生产账号。
本模拟服发包只能验证兼容性，不能证明原服经济公式；数值复原须用可信原记录或当时实测。

1. **生产成本/时长**：隔离账号、空内政部队、原田地G1Lv1；分别试10秒免费配方、
   5级开放的900秒/10gold配方。记录开工前后PP、资源，提交的buildingId/productId，
   响应dueTime/now、重登tasks.producings。批量用不同配方并在返回成功后重试一次。
   核对 GameRestarter 是否在 errorReason 时阻断 payoutCosts；失败后需重读，不能UI二次扣费。
2. **实际收获与道路**：固定建筑等级、配方和内政，比较无路、单贴边、仅贴角、多路、
   不连城与连城；到期前移路与开工前移路分开。记录每个 reward 项、玩家exp、building.exp、
   collaborator、PP。13..17 的预览插值不是最终产出；用足够样本区分随机、等级插值和道路取整。
   然后单独改变城代/其他内政位置、同组道路技能等级及两张同技能，不能同时改多个因素。
3. **有限耐久**：有可信原记录时比较金山10→9，开工后取消，到期未收时重登、最后1→0。
   决定扣次时点与取消是否退款；最后一次删除建筑/占格/任务与发奖必须原子。
4. **支城**：定位原任务po_mission_00281(index306)，捕获首次接受、两组达成、关闭及
   第一次switchMap(1)/getMapData。必须保存原40×40未开拓格子、地图名称、默认背景和部署键；
   仅见7500或unlockBits不足以构造地图。验证整话完成标志，不拿area10最后一步冒充完成。
5. **背景**：仅在真实可用的支城账号上试近/远景商品，捕获shopItems、购买resources、
   getBackgrounds、setBackground(mapId=1)、重登mapProfiles["1"]。校验默认背景是否免费、
   禁用商品是否应隐藏、场景parameterId对应包是否可加载。缺包报stub has no assets；
   未实现资格/结算或坏引用报no stub response。
6. **好友助产**：待E/I确定权限及双账号事务后，先做不结算的抓取；记录owner/visitor
   各自PP、奖励、每日quota、好友解除竞态。禁止用两次单玩家保存模拟原子结算。

其余 wrapper-only 查询不拿getMapData代替响应；先从原UI或当时抓包找到实际调用者。
