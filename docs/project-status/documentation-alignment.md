## 已对齐的语义

- README、中文导航、架构和工具索引统一双入口。云端 stub 18080；本地 stub 18081、代理 18082、
  MySQL 3307；原域名共享本机网关 80，游戏关闭后切服。本地运行代码固定目录，开发留在工作树。
- 任务 5 单体田地开工和受限收获已接入；通用配方/道路、批量/取消/加速未完成。
  `completeTasks` 同时承担建设完成和这一个受限生产结算，不能继续描述为“生产一概未实现”。
- 冒烟脚本对未接受任务 5 的新测试账号检查资格拒绝，而非把它误判为占位；
  其余三个未实现写入继续要求明确失败、不写档。对应 HTTP 检查已通过并清理临时账号。
- 当前 pre-auth 名单为 7 个；32 个管理/调试入口先行关闭，debugLoginCog 不在放行名单。
  调试登录密钥为空会禁用，不是自动开放；observe 不是数据库故障回退。平台票据校验缺口明确保留。
- `{}` 可能是合法空库存或原版写入确认；是否占位由对应处理器和客户端消费点判断。
- 代码/资源/数据分别发布。代码通过 Git 追溯，有本机已核对旧资源时不额外积累云端永久副本；
  背景工具支持 baseline 与临时恢复。其他发布工具以实际参数为准，不虚构通用开关。
- `ONI_BUILD_ID` 是发布标记，环境角色是连接目标，Git HEAD 是源代码版本，三者不相互替代。
  发布过不等于已合并，原生可加载不等于全部 UI/玩法通过。
- 固定运行源码目录和当前活动进程也分别核对；私有配置可能被并行本地任务切到开发工作树。
  本轮收尾保留食事处任务的本地版本，仅同步云端和固定源码目录，不声称活动本地进程与云端同版。
