## 连接方式（不要混用）

两份 INI 均保持：

```ini
StartUrl=http://passport.86joy.com/index.php/gwz/client/login/
FinalUrl=http://game-onisoul.86joy.com/client/app.html
```

| 模式 | hosts 的目标 | 转发路径 |
|---|---|---|
| Local | 127.0.0.1 | 本机 proxy:80 → 本机 stub:18080，需要本机 MySQL/表/资源 |
| Lan | 局域网服务机 IPv4 | 局域网服务机 proxy:80 → 同机 stub:18080 |
| Cloud | 云服公网 IPv4 | 云服 proxy:80 → 云服回环 stub:18080 |
| CloudRelay | 127.0.0.1 | 本机 proxy:80 → 云服 proxy:80 → 云服回环 stub:18080 |

`tools/configure_client.ps1` 默认只预览，加 `-Apply` 才写入。它备份两个 INI 和需要修改的 hosts，
保留原文件编码，检查四个游戏域名。`-SkipHosts` 只在现有四个映射已经匹配时允许使用。
本次 Windows 没有 hosts 写权限，因此采用 CloudRelay，无需改动 hosts；这不影响云服供其他客户端使用。

```powershell
# 管理员 PowerShell：云服直连（地址由使用者填写）
powershell -NoProfile -ExecutionPolicy Bypass -File tools/configure_client.ps1 -Mode Cloud -ServerAddress <云服IP> -Apply
# 当前机器：利用已有 loopback 映射，只调整两份 INI
powershell -NoProfile -ExecutionPolicy Bypass -File tools/configure_client.ps1 -Mode CloudRelay -ServerAddress <云服IP> -SkipHosts -Apply
# 本机转发器必须在客户端启动期间运行
python tools/proxy80.py --host 127.0.0.1 --listen 80 --upstream-host <云服IP> --upstream 80
# 后续启动客户端并复用/启动隐藏转发器（不会改游戏窗口尺寸）
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start_cloud_client.ps1 -ServerAddress <云服IP> -ClientRoot <客户端目录>
```

## 资源结论与未完成部分

1. 客户端 QtWebKit 缓存共 164 条记录，提取出 128 个真实 UnityWeb 包；云端原有 124 个，与客户端副本逐字节一致。另 4 个 questBanner 包可直接补齐，不生成替代资源。
2. 初次审核的历史日志中有 10 个当时无法解析的资源 URL，见 `audit-missing-assets.json`。后续已补入两个经同角色素材校验的重建包，另外发现一个场景 URL 使用了不同编码的哈希，而对应资源本体已有。其余来源与当前状态见 [后续复核](recovery-20261115.md)；这些历史请求不等于全部由真实客户端产生，也不代表游戏全部缺失资源数。
3. 402 个接口中 379 个使用 `placeholders`；其余 23 个有专门逻辑，也不等于完整玩法。任务推进主要接受客户端上报，尚无完整的条件核验、经济平衡与防作弊实现。
4. 云端 `mission_chain.py` 原有未提交的自动开启首个任务补丁保留。它不是本次新增改动，也尚未由本次真机任务流证明；不得用内存测试宣称真实 UI 新手引导已打通。
5. 两张清单表 `combo.json`、`strategy_battlefield.json` 仍缺失；服务器实际拥有 106/108 张客户端表及 4 张运行时表。
6. 仓库没有桌面监控面板或 SSE 实现，云端还留有 `onisoul-panel.service` 的 failed/not-found 状态。本次不把不存在的监控功能描述为已修复。
7. PC 内嵌 Unity 的完整新号引导与所有场景未验收；HTTP/MySQL 测试只证明服务端链路与对应处理逻辑。
8. 原 HTTP/Unity 3.5 客户端链路仍使用明文 HTTP；新增脱敏不等于网络加密。历史日志包含旧凭据，应仅限服务器维护者访问。
